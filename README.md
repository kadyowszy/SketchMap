# SketchMap (Beta)

Turn a photo of a hand-drawn game level into an editable 2D grid map, then export it as **JSON** or a **Godot scene (.tscn)**.
Works offline. No account, no install of Python, nothing to compile.

## Download

**[Go to the Releases tab](../../releases/latest)** and download the latest `SketchMap` zip for your system.

1. Unzip the folder.
2. Open `SketchMap.exe`.
3. Import a photo of your sketch (black pen on white paper) and export your level.

You do not need to build or compile anything.

## Beta build

From a photo, SketchMap currently recognizes only:

- **Boundary**: one closed rectangle around the whole map
- **Wall**: thick straight strokes
- **Player start**: an arrow
- **Enemy spawn**: a hollow triangle
- **Door**: a hollow box in a wall gap

Other symbols are not recognized yet. You can still place them yourself in the Edit page.

## Help

Press **F1** in the app for the user manual.
